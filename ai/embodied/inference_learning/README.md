# GR00T 推理框架学习课程（中文教学）

> 目标：复习 GR00T **推理框架** 的设计、主要模块的作用与原理，配合阅读真实代码。
> 教学方式：以"老师 + 章节化笔记"循序渐进推进；边学边更新本目录文档。

## 课程定位（读者前置知识）

- 需要 Python、PyTorch(torch.Tensor / nn.Module / autocast) 基础。
- 需要基础深度学习常识：Transformer、注意力、扩散模型/流匹配（flow matching）概念。
- 需要能在本工作区翻阅代码：`Isaac-GR00T/`、`groot_ops/`、`vllm_evas/`、`tao/vla_infer/`。

## 课程主线（我们回答什么问题）

"给机器人一个传感器观测（视频 / 状态 / 语言指令），GR00T 推理框架
 如何在 <推理服务> 中把它变成一串机器人可执行的动作？"

这条主线从外到内拆成 10 章（见 `00_教学计划.md`）：

```
观测(obs)
  │  ① 服务入口接收 & ② 数据变换(归一化)
  ▼
Gr00tPolicy.get_action()
  ├─ Backbone (冻结 VLM, Eagle)        → 把视频/文本编码成特征
  └─ Action Head (扩散/流匹配 DiT)     → 从噪声一步步去噪生成动作
  ▼
动作(action)  ← 反归一化 → 输出
```

## 如何使用本课程

1. 按章号顺序阅读（`00` → `10`），每章都在真实代码里打开对应文件对照。
2. 每章末尾有一个 **"自己动手"** 小节（阅读提示 / 小练习），建议先尝试再往下。
3. 遇到疑问可以在 `## 疑问与批注` 小节记录，方便后续回顾与向老师提问。

## 教学理念：案例 → 原理 → 迁移（本课程对具身智能的普适意义）

> 提问：本课程针对 gr00t 设置和展开，对**具身智能的普遍原理与实现**的学习理解是否有意义？
> 结论：**有意义**——价值不在 gr00t 的名字，而在其背后的**普遍原理**与**可复用方法论**。gr00t 只是"容器"，
> 原理和方法论才是"本质"。

### 1. 能迁移到"任何具身智能"的普遍原理（本课程的核心可迁移资产）

| 范畴 | 普遍原理 | 换到 pi0/ACT/OpenVLA/扩散策略/其它 NPU 仍成立 |
|---|---|---|
| 认知框架 | VLA = Vision→Language→Action；"慢感知规划(S2)+快高频控制(S1)"架构无关 | ✔ |
| 数据流 | 观测→归一化→模型→反归一化→动作；模型在标准空间、出口还原物理单位；变换须**可逆、逆序 unapply** | ✔ |
| 生成式动作头 | 动作分布**多模态**→ 回归求均值坍缩成畸形轨迹 → 用**扩散/流匹配采样**一个模式 | ✔ |
| 训练=学去噪，推理=迭代去噪 | forward 加噪学速度场 ↔ get_action 从噪声还原，同一枚硬币两面 | ✔ |
| 两个数字 | `denoising_steps`(精修几轮)≠`action_horizon`(一次多长)；部署用**滑动窗口**衔接 | ✔ |
| 具身抽象 | 一个模型 + category-specific 头 + 元数据适配**多本体** | ✔ |
| 冻结主干 | 冻结 VLM 主干省显存/保语言能力；只训投影+动作头 | ✔ |
| 训练/推理分离 | `forward`(出 loss,可反向) vs `get_action`(无梯度采样) | ✔ |
| **优化方法论** ⭐ | **先可测量→可归因→可优化→可回归**；三层分离(设备/host/搬运)、device-resident、golden 精度闸门 | ✔ 全书最可迁移资产 |

### 2. gr00t 特有、不能照搬的部分（只是"案例"）
- 具体模型名/结构：EagleBackbone、SigLIP、Qwen3、FlowmatchingActionHead、DiT 层配置。
- 具体张量形状/数字：`296/49/16`、`[1,296,2048]`、`action_pred [1,16,32]`。
- 具体代码实现：`Gr00tPolicy`、`prepare_input` 等类/方法（实现 ≠ 原理）。
- NPU 细节：VISA、Die/Cluster/Core、具体融合算子名、双 Die 布局策略。

### 3. 学习方法建议（如何抽出普遍价值）
1. 每学一个 gr00t 机制，先问："这是**本模型特有的实现**，还是**任何 VLA 都躲不掉的原理**？"
   （例：`prepare_input` 分流 → 普遍原理=混合精度+离散量保真；`Gr00tPolicy` → 普遍原理=策略层编排、隐藏模型内部。）
2. 把 gr00t 当"唯一能跑的真实代码样例"：它给你每个原理对应的**真实落线**（flow matching 训练加噪代码、
   归一化逆序 unapply），这是最稀缺的部分。
3. 做**"换壳练习"**：想象换成 pi0 或 ACT，哪些类/变量会变、哪些不变——不变的就是普遍原理
   （参见第 0 章 迁移视角 / 第 10 章自测）。

### 4.（可选教学设定调整）教学时标注"→ 普遍原理"
每讲一个 gr00t 机制，可额外标注：**它对应的普遍原理是什么、换成别的 VLA 会怎么变**——
把"案例 → 原理 → 迁移"结构贯穿后续各章，让本课程对"具身智能"更普适。
（如选择开启，老师在后续章节注释里附带 `[普遍原理]`/`[迁移]` 标记。）
